# Python Type Casting & User Input Lab

## 📌 Introduction
In this lab, you handle user input data and apply **type casting** in Python to ensure data is in the correct format for processing. Each exercise presents a real-world scenario illustrating the necessity of explicit type casting when working with `input()`.

---

## 🎯 Goal
Gain a deeper understanding of type casting in Python and learn how to apply it effectively when handling user input.

---

## 🛠️ Objectives
* **Exercise 1:** Apply explicit type casting to convert user inputs into their required data types (e.g., `int`, `float`, `str`).
* **Exercise 2:** Use type casting in mathematical calculations to compute and display the correct bill total.
